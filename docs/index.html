Text your Mac.
It does the thing.

You're out. You remember something you left at home. You text your own Apple ID — and your Mac gets on with it.

you  →  MACman wake up
mac  →  MACman here. Send your code.
you  →  482913
mac  →  MACman ready. What do you need?
you  →  how many PDFs are in my Downloads?
mac  →  There are exactly 28 PDF files in Downloads.
you  →  end session
mac  →  Stopped. 1 task this session, $0.000.

That $0.000 is the point.

Set up

git clone https://github.com/Nikhilnmv/MACman.git && cd MACman
python3 -m venv .venv && .venv/bin/pip install -e .
cd helpers && swift build -c release -Xswiftc -DMACMAN_TOOLS && cd ..
.venv/bin/python -m macman.main setup

The last command walks you through permissions, who's allowed to reach your Mac, and your login code — then runs a real task to prove it works.

A one-line install is coming. brew install nikhilnmv/tap/macman is the plan, but the tap isn't published yet — so the honest instructions are the ones above.

Why it's different

Your personal files never leave your Mac. Documents, mail, notes and calendar are handled by Apple's on-device model, which ships with macOS. No download, no daemon, no API key.

The part that decides private or cloud makes no network call at all — asking a cloud model "is this private?" has already leaked the filename.

Every number is measured, with the method published, in RELIABILITY.md — including the things that scored badly and were dropped.

What it will never do

  • Unlock your Mac. It can lock it. macOS blocks the reverse, and MACman holds no password.
  • Ask for your login password. Sessions use a code from your authenticator, revocable on its own.
  • Answer a stranger. Messages from anyone not on your list are dropped in silence.
  • Delete without asking. And deleting means the Trash, never rm.
  • Read your keys. ~/.ssh, ~/.aws and your Keychain are refused in code — not by asking the model nicely.
  • Send an email. It drafts; you press send.

Every permission is optional, and MACman tells you what each one would unlock rather than demanding them up front. One command turns everything off: scripts/revoke_all.py --revoke

Being honest about limits

It runs on a small on-device model, so it does known things reliably rather than anything you can imagine. It can't see images, can't operate apps that offer no automation, and won't click around your screen guessing — that approach measured 50% correct, and a wrong click doesn't give a wrong answer, it presses something.

Harder work — reading code, fixing bugs — is handed to Claude Code, which uses your own Claude subscription.
